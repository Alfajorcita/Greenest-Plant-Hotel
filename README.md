Greenest – Plant Hotel 🌱

Description

A Java application developed as part of an Object-Oriented Programming (OOP) course at Nackademin.

The program calculates the daily amount and type of liquid required for different plants based on their type and height.

Features

Search for plants by name.

Calculate daily liquid requirements.

Display liquid amounts and types.

Handle invalid user input.

Technologies

Java

IntelliJ IDEA

Programming Concepts

Encapsulation

Inheritance and polymorphism

Abstract classes and interfaces

Enums

Collections (ArrayList)

About

A learning project focused on applying OOP principles and writing structured, maintainable Java code
